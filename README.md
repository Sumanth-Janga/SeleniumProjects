# Amazon India – Selenium Automation Testing Project 🚀

## 📌 Project Overview

This repository contains my ongoing **Web Automation Testing Project** based on the Amazon India e-commerce website using Selenium WebDriver with Java.

The primary objective is to automate real-world e-commerce functionalities, practice Selenium concepts, and develop a strong foundation in automation testing.

This project is currently under development. I will continuously add new test cases, automation scripts, and framework components as I progress.

## 🛠️ Technologies & Tools

- **Programming Language:** Java
- **Automation Tool:** Selenium WebDriver
- **Testing Framework:** TestNG
- **Build Tool:** Maven
- **Locators:** XPath, CSS Selectors, ID, Name, Class Name
- **IDE:** IntelliJ IDEA
- **Version Control:** Git & GitHub

## 🎯 Current Implementation

- Amazon India website navigation.
- Product search automation.
- Locating web elements using Selenium locators.
- Handling XPath and dynamic XPath.
- Clicking elements and interacting with web components.
- Retrieving and validating product information.
